## Add auditable compaction evidence campaigns

Promote the private compaction-score research harness into reviewed campaign
CLIs for deadline outcomes and sweeps, production overlap, matched quality,
task utility, human calibration, and five-track evidence aggregation.

The campaigns write resumable artifacts with command receipts, source hashes,
typed validators, and deterministic report statistics. This changes only the
private benchmark package and does not change a published runtime API or
version.
